Growser — how updates work

What each platform does to keep itself current, in plain terms. No marketing.

Growser is a Chromium fork, so it inherits Chromium’s updater rather than inventing one. What differs between Windows and macOS is how the browser is delivered and what the operating system does with an unsigned binary. Both are described below — including where each path is not finished yet.

Windows

  • Distribution. The installer is a GitHub release asset (GrowserSetup.exe on dsfox-idea/brave-core); its SHA-256 is in the release notes.
  • Updates. Chromium’s updater (Omaha 4) ships inside the installer and registers a scheduled task. It asks https://backend.growser.org/update, which answers the Omaha 3.1 protocol from a static manifest. Publishing a release means editing that manifest (see #51).
  • Signing. None yet. SmartScreen shows “Windows protected your PC” and the publisher reads as unknown. A free certificate from SignPath Foundation is the path and is now unblocked (#75).

macOS

  • Distribution. An Apple Silicon (arm64) build, ditto-zipped as Growser-mac-arm64.zip on the same GitHub release. Download, unzip, drag Growser.app to /Applications. There is no Intel (x86_64) build yet.
  • Updates. The active updater on macOS is Sparkle: the browser reads a signed appcast at the URL compiled into it (https://growser.org/sparkle/developer-arm64/appcast.xml), which advertises the same archive the download button serves, signed with our EdDSA key. Chromium’s updater (Omaha 4) is the long-term plan for parity with Windows but is deferred (#51), so Sparkle is what keeps a running macOS install current today.
Why the macOS channel is “developer”. The appcast path is built from the build’s channel, and our releases are non-official (no service keys, no ThinLTO, no exact-SDK gate), so the browser reports its channel as developer — hence sparkle/developer-arm64/. An official build would report stable and use sparkle/stable-arm64/. The name is honest about what the build is; it is not a “dev” build in the nightly sense.
