macOS will warn you. This build is not signed with an Apple Developer ID, so Gatekeeper blocks it on first open (“cannot be opened because the developer cannot be verified”). Right-click the app → Open, or run xattr -cr /Applications/Growser.app. It is an Apple Silicon (arm64) build. See our code signing policy.
Windows will warn you. This build is not code-signed yet, so SmartScreen shows “Windows protected your PC” and the publisher reads as unknown. Choose More info → Run anyway, or check the SHA-256 on the release page first. A certificate is being arranged; see our code signing policy.
